# Asá: Frontend First

Build Phase 1 of a production-ready marketplace application called Asá.



IMPORTANT:



This phase is ONLY for the frontend UI/UX.



Do NOT create any database tables.



Do NOT connect Supabase.



Do NOT build backend logic.



Do NOT build authentication logic yet.



Do NOT create the Admin Panel.



Do NOT create the Super Admin Panel.



Do NOT create the Support Agent Panel.



Do NOT implement bookings, payments, messaging, wallet, notifications, referrals, reviews, provider verification, or any backend functionality.



This phase is strictly for creating a beautiful, premium, modern, production-quality user interface.



==================================================

SPLASH SCREEN (LOADING SCREEN)

==================================================



The application must begin with a premium splash screen that lasts approximately 6–7 seconds before navigating to the Home page.



This splash screen should feel luxurious, smooth, and memorable.



Background:

• Deep Forest Green (#0F5A43 or similar)



Center:



Display ONLY the word:



Asá



The text should be metallic gold with a premium finish.



Do NOT display the logo icon.



Only display the text "Asá".



Animation:



The word "Asá" should animate as if it is being written from left to right.



The animation should continuously draw each letter smoothly until the complete word "Asá" is fully revealed.



The writing effect should repeat gently during the loading period until the final second.



At the end of the loading animation:



• The complete word "Asá" remains fully visible.

• A soft golden glow appears around the text.

• The animation pauses briefly before transitioning to the Home page.



Below the word "Asá":



Display the slogan:



"Trusted. Verified. Nearby."



(The slogan should be easy to change later.)



At the very bottom of the screen display:



Powered by HEPTALABS



This text should NOT be gold.



Use either:



• White

OR

• Soft Sky Blue



It must clearly contrast with the gold "Asá" text.



The splash screen should include elegant fade-in and fade-out transitions.



Do not include loading percentages.



Do not include progress bars.



The writing animation itself should communicate that the application is loading.
